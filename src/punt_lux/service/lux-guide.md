# Using Lux

Lux is a visual surface for this project. Use it for tables, plots, dashboards
and interactive controls when the user wants to see or interact with the result.
Use the Lux skills for common layouts rather than rebuilding them from scratch.

- Run `/lux` to check repo integration and the personal display preference.
- Run `/lux enable` or `/lux disable` to change your checkout's integration.
  Pass `project` only when changing the team's policy in a reviewed change.
- Run `/lux y` or `/lux n` to change your display preference without changing
  repo integration, permissions or the terminal service.
- If enabled but the window is unavailable, run `lux doctor`. Do not register
  or poll for clicks on applet-owned menus; their applets handle those clicks.
