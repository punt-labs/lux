Three ways to find a window

One menu model, three views, on a menu bar that reads Lux · Projects · Terminals · Windows · Help. Projects groups by repository only: two lux sessions share one lux submenu, and a second Beads becomes Beads (2). The session is in the window title and the i button, not the menu. Terminals groups by the machine the shell runs on. Its New lists launchers: Shell first, then the named commands each machine lists in its own terminals.toml. It asks which machine only when more than one offers the launcher. Add launcher… shows how an agent or you adds one, and the rule that agents need the machine's permission. Windows lists every open window. Use the menu bar, or click the desktop for the same menus. Switch between one machine and three to see the host level appear and disappear.

The rules

Projects
By repository only. Two sessions in one repository share its submenu; repeated item names get (2). A client with no repository (voxd) keeps its own submenu. No terminals.
Terminals
By the machine the shell runs on. With one machine the list is flat. New lists launchers, then the machine if more than one offers it.
Launchers
A name and a command, in each machine's ~/.punt-labs/lux/terminals.toml, or added at runtime with lux term launcher add / the term_launcher_add MCP tool. A click carries only the name; that machine's luxd-pty runs the command. Runtime launchers last until luxd-pty restarts, and any runtime registration, MCP or CLI, needs allow_runtime_launchers = true in that machine's file. Lux never writes the file.
Rename
lux term rename "name". Typed inside a terminal, it renames that terminal: the shell knows its own session.
Focus
A window you open from a menu, pill or Windows entry takes focus (blue outline, blinking cursor). One an agent opens appears behind yours and never takes focus.
Windows
Every open window, flat, by its full title. Minimized ones are greyed.
Titles
machine :: program on a terminal. The machine is dropped while only one is connected.

– minimizes to the dock on every window. × ends the content, only where the owner can.
