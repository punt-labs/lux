% ============================================================
\section{Introduction}
% ============================================================

An agent patches a single Element-ABC element by sending a mapping of field
names to new values.  \texttt{Element.apply\_patch} applies the entries in
order, each through a \texttt{\_set\_<key>} setter, and promises
\emph{all-or-nothing}: if any setter rejects its value, every field the patch
already touched is restored and the element is left exactly as it was before the
patch began.  A composed table also has an \emph{observer} --- the filtered
table's Hub-side model --- which folds a selection write into a full selection
spanning filter-hidden rows, and folds an external \emph{rows} write in as its
new dataset.  The property that must hold is that a rejected patch produces no
observable change at all, that a successful patch leaves the model reflecting the
patch's final values, and that the model's fold does not depend on the order in
which one patch's notifications happen to fire.

The same class of defect recurred across four fix/review rounds:

\begin{enumerate}
  \item the table's selection lived in a \emph{mutable} composed model, so the
    shallow \texttt{dict(vars(self))} snapshot captured the model
    \emph{reference}; a setter mutated it in place, and rollback restored a
    reference to an already-mutated model;
  \item the selection setter notified observers \emph{inside} the patch, so the
    model folded an intermediate selection before a later key was rejected;
    rollback restored the fields but could not un-fire the notification;
  \item the model absorbed an external rows refresh as its dataset and
    re-projected by issuing a \emph{nested} \texttt{apply\_patch} from inside the
    outer patch's commit-phase notification; without a guard the model folds its
    own filtered subset back in as the dataset, unbounded;
  \item one \texttt{apply\_patch} that set \emph{both} rows and selection raced:
    the commit flushed the rows notification first, the model re-projected off a
    \emph{stale} full selection and overwrote the freshly-set selection, and the
    later selection notification read the clobbered value.
\end{enumerate}

Round~1 was closed by making the composed model immutable; round~2 by deferring
notification to commit; round~3 by giving each \texttt{apply\_patch} its own
buffer (reset to \texttt{None} on entry) and a \texttt{\_reprojecting} boolean
that excludes the model's own inner write from re-absorption; round~4 by making
the rows-absorb \emph{batch-aware} --- it folds the element's \emph{committed}
selection before re-projecting, so reading the element's post-patch state makes
the fold independent of which notification the commit flushes first.  All four
fixes survive here as fidelity variants (Section~\ref{sec:fidelity}) that
reintroduce each defect to confirm the model still detects it.  Empirical
round-by-round fixing kept missing an interleaving, so this document models the
boundary as a finite state machine over a bounded \emph{stack} of patch frames
whose commit delivers buffered notifications in any order, letting ProB
enumerate every patch shape, nesting order, and intra-batch delivery order
exhaustively.

% ============================================================
\section{Basic Types}
% ============================================================

Because the reentrancy is tied to specific fields (a \texttt{rows} write triggers
a re-projection; a \texttt{selected\_row\_ids} write only folds), the carriers
are modelled concretely as free types rather than as unconstrained given sets.
This bakes in exactly the topology under test and keeps every carrier finite, so
ProB is exhaustive without a \texttt{DEFAULT\_SETSIZE} parameter.

\begin{zed}
  FMODE ::= setting | flushing
\end{zed}

A patch frame is \texttt{setting} while its setters run (buffering notifications)
and \texttt{flushing} while its committed notifications are delivered.

\begin{zed}
  SWITCH ::= off | on
\end{zed}

Used for the \texttt{\_reprojecting} guard and for a frame's ``is a
re-projection'' marker.

\begin{zed}
  GOODVAL ::= a | b
\end{zed}

The values a field may validly hold.  Two distinct values are enough to show a
field \emph{changing} and to distinguish an agent's pushed value (\texttt{b},
say, a fresh dataset or a patched selection) from a stale or subset value
(\texttt{a}), so that ``the model absorbed its own subset'' and ``the
re-projection clobbered the patched selection'' are both observable.

\begin{zed}
  KEY ::= krows | ksel
\end{zed}

The two fields under test: \texttt{krows} (the element's rows/dataset) and
\texttt{ksel} (the element's selection).

A patch step either sets a known field to a valid value or names a value the
setter rejects:

\begin{zed}
  STEP ::= setK \ldata KEY \cross GOODVAL \rdata | badK \ldata KEY \rdata
\end{zed}

\texttt{setK}: set field \texttt{k} to valid value \texttt{g} (the setter
succeeds).  \texttt{badK}: set field \texttt{k} to a rejected value (the setter
raises, triggering rollback).  Each constructor is an injection and their ranges
partition \texttt{STEP}, so the test $head~q \in \ran setK$ distinguishes them.
Two projections recover a step's target and (for a set) its value:

\begin{axdef}
  stepKey : STEP \fun KEY \\
  stepVal : STEP \pfun GOODVAL
\where
  \forall k : KEY; g : GOODVAL @ \\
  \quad~ stepKey~(setK~(k, g)) = k \land stepVal~(setK~(k, g)) = g \\
  \forall k : KEY @ stepKey~(badK~k) = k \\
  \dom stepVal = \ran setK
\end{axdef}

The queue bound keeps every patch (agent-built or re-projection-generated)
finite, and the stack bound caps the reentrancy depth so the carrier is finite:

\begin{axdef}
  maxlen : \nat \\
  maxdepth : \nat
\where
  maxlen = 2 \\
  maxdepth = 3
\end{axdef}

A patch of length two exhibits ``set a watched field, then fail on a second'' and
the dual \texttt{\{rows, selection\}} patch; a re-projection writes exactly two
keys (\texttt{krows} then \texttt{ksel}).  A stack of depth two is the deepest the
correct design reaches (an outer patch and its one nested re-projection); depth
three gives ProB room to exhibit the unbounded self-recursion the guard prevents.

% ============================================================
\section{The Patch Frame Stack}
% ============================================================

Reentrancy means more than one \texttt{apply\_patch} is live at once: the outer
patch is mid-commit, delivering a notification, when the model starts a nested
patch.  Each live call is a \emph{frame} with its own rollback snapshot, its own
notification buffer, and (once committing) its own set of notifications still to
deliver.  A frame is the Z counterpart of one Python \texttt{apply\_patch} stack
activation.

The stack of frames is modelled as five parallel sequences kept in lockstep, one
per frame attribute, rather than a sequence of a composite frame type --- ProB
enumerates a composite type's unbounded sequence field as an unconstrained
\texttt{ANY}, so the flat encoding is what keeps the search finite.  Frame $i$ is
the tuple $(smode~i,\, squeue~i,\, ssnap~i,\, sprops~i,\, sreproj~i)$, and the
top (innermost live) frame is at index $\# smode$:

\begin{itemize}
  \item \texttt{smode} --- \texttt{setting} while the frame's setters run,
    \texttt{flushing} while its committed notifications are delivered.
  \item \texttt{squeue} --- the frame's unprocessed setters.
  \item \texttt{ssnap} --- its rollback snapshot, a value copy of the fields as
    they were when the frame began.
  \item \texttt{sprops} --- the props this frame has flagged.  While
    \texttt{setting} this is the per-patch notification \emph{buffer}; on commit
    the same set becomes the props still to \emph{deliver}, and each is delivered
    in any order --- modelling that a race over delivery order must not change the
    outcome.
  \item \texttt{sreproj} --- \texttt{on} for a frame that is the model's own
    re-projection, whose lifecycle raises and lowers the guard.
\end{itemize}

% ============================================================
\section{State}
% ============================================================

Alongside the stack, the state carries the element's field values and four model
scalars.  \texttt{dataset} is the model's absorbed dataset; \texttt{msel} is the
model's full selection.  \texttt{extern} and \texttt{externsel} track the last
\emph{external} (agent, non-re-projection) rows and selection an outer patch
committed --- the values the agent actually pushed, which the model's dataset and
selection must equal.  The predicate carries only the lockstep and length bounds;
the atomicity property (Section~\ref{sec:inv}) is deliberately \emph{absent}, so
a violating state stays reachable and ProB can find it.

\begin{schema}{Sys}
  smode : \seq FMODE \\
  squeue : \seq (\seq STEP) \\
  ssnap : \seq (KEY \fun GOODVAL) \\
  sprops : \seq (\power KEY) \\
  sreproj : \seq SWITCH \\
  build : \seq STEP \\
  fields : KEY \fun GOODVAL \\
  msel : GOODVAL \\
  dataset : GOODVAL \\
  extern : GOODVAL \\
  externsel : GOODVAL \\
  guard : SWITCH
\where
  \# smode = \# squeue \land \# smode = \# ssnap \\
  \land \# smode = \# sprops \land \# smode = \# sreproj \\
  \# smode \leq maxdepth \\
  \# build \leq maxlen \\
  \forall i : \dom squeue @ \# (squeue~i) \leq maxlen
\end{schema}

The element is \emph{idle} exactly when the stack is empty ($\# smode = 0$).
\texttt{build} is the outer patch an agent assembles one step at a time while
idle; building step-by-step keeps every input a single \texttt{STEP} over the
finite \texttt{STEP} carrier, so ProB enumerates patch shapes without enumerating
arbitrary sequences.  The element's rows/dataset field (\texttt{fields~krows})
and the model's dataset (\texttt{dataset}) diverge under a filter --- the element
shows the visible subset while the model holds the full dataset --- which is why
the dataset invariant compares \texttt{dataset} to \texttt{extern}, not to
\texttt{fields~krows}.  \texttt{guard} is the \texttt{\_reprojecting} boolean.

\section{Initialization}
% ============================================================

\begin{schema}{Init}
  Sys'
\where
  smode' = \langle \rangle \land squeue' = \langle \rangle \\
  \land ssnap' = \langle \rangle \land sprops' = \langle \rangle \\
  \land sreproj' = \langle \rangle \land build' = \langle \rangle \\
  fields' = \{ krows \mapsto a, ksel \mapsto a \} \\
  msel' = a \land dataset' = a \\
  extern' = a \land externsel' = a \\
  guard' = off
\end{schema}

A single initial state: no patch in progress, every field holds \texttt{a}, the
model's dataset and selection are \texttt{a} (consistent with the fields), the
last external rows and selection were \texttt{a}, and the guard is down.

% ============================================================
\section{Beginning a Patch}
% ============================================================

An agent assembles the outer patch one step at a time while idle, appending each
step to \texttt{build} up to the length bound.  Any step is admissible, including
a \texttt{badK} that will later trigger a rollback:

\begin{schema}{Enqueue}
  \Delta Sys \\
  p? : STEP
\where
  \# smode = 0 \\
  \# build < maxlen \\
  build' = build \cat \langle p? \rangle \\
  smode' = smode \land squeue' = squeue \\
  \land ssnap' = ssnap \land sprops' = sprops \land sreproj' = sreproj \\
  fields' = fields \land msel' = msel \land dataset' = dataset \\
  \land extern' = extern \land externsel' = externsel \land guard' = guard
\end{schema}

\texttt{BeginOuter} applies the assembled patch: it pushes one frame onto each
stack sequence with \texttt{squeue} taking the built steps, takes the rollback
snapshot, and clears \texttt{build}.  The empty patch is admissible:

\begin{schema}{BeginOuter}
  \Delta Sys
\where
  \# smode = 0 \\
  smode' = smode \cat \langle setting \rangle \\
  squeue' = squeue \cat \langle build \rangle \\
  ssnap' = ssnap \cat \langle fields \rangle \\
  sprops' = sprops \cat \langle \emptyset \rangle \\
  sreproj' = sreproj \cat \langle off \rangle \\
  build' = \langle \rangle \\
  fields' = fields \land msel' = msel \land dataset' = dataset \\
  \land extern' = extern \land externsel' = externsel \land guard' = guard
\end{schema}

% ============================================================
\section{Applying a Patch}
\label{sec:apply}
% ============================================================

Each step processes the head of the top frame's queue.  A successful set installs
the value into the element and \emph{buffers} the notification for that prop into
the top frame's own \texttt{sprops} entry --- it does not fire it:

\begin{schema}{ApplyStepTop}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = setting \land squeue~(\# smode) \neq \langle \rangle \\
  head~(squeue~(\# smode)) \in \ran setK \\
  fields' = fields \oplus \\
  \quad~ \{ stepKey~(head~(squeue~(\# smode))) \mapsto
           stepVal~(head~(squeue~(\# smode))) \} \\
  squeue' = squeue \oplus \{ \# smode \mapsto tail~(squeue~(\# smode)) \} \\
  sprops' = sprops \oplus \\
  \quad~ \{ \# smode \mapsto (sprops~(\# smode) \cup
           \{ stepKey~(head~(squeue~(\# smode))) \}) \} \\
  smode' = smode \land ssnap' = ssnap \land sreproj' = sreproj \\
  msel' = msel \land dataset' = dataset \land extern' = extern \\
  \land externsel' = externsel \land guard' = guard \land build' = build
\end{schema}

When the top frame's queue is empty it commits: it flips to \texttt{flushing} and
its buffered \texttt{sprops} become its delivery set.  An outer patch records the
values it wrote to \texttt{krows} and \texttt{ksel} as the new external dataset
and selection; a re-projection frame records neither, because its writes are the
filtered subset and projection, not an agent push:

\begin{schema}{CommitTopOuter}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = setting \land squeue~(\# smode) = \langle \rangle \\
  sreproj~(\# smode) = off \\
  (krows \in sprops~(\# smode) \implies extern' = fields~krows) \\
  \land (krows \notin sprops~(\# smode) \implies extern' = extern) \\
  (ksel \in sprops~(\# smode) \implies externsel' = fields~ksel) \\
  \land (ksel \notin sprops~(\# smode) \implies externsel' = externsel) \\
  smode' = smode \oplus \{ \# smode \mapsto flushing \} \\
  squeue' = squeue \land ssnap' = ssnap \\
  \land sprops' = sprops \land sreproj' = sreproj \\
  fields' = fields \land msel' = msel \land dataset' = dataset \\
  \land guard' = guard \land build' = build
\end{schema}

\begin{schema}{CommitTopReproj}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = setting \land squeue~(\# smode) = \langle \rangle \\
  sreproj~(\# smode) = on \\
  smode' = smode \oplus \{ \# smode \mapsto flushing \} \\
  squeue' = squeue \land ssnap' = ssnap \\
  \land sprops' = sprops \land sreproj' = sreproj \\
  fields' = fields \land msel' = msel \land dataset' = dataset \\
  \land extern' = extern \land externsel' = externsel \\
  \land guard' = guard \land build' = build
\end{schema}

A rejected step aborts the top frame: its fields are restored from its own
snapshot, its buffer is discarded unfired, and the frame is popped off every
stack sequence.  If the aborted frame was a re-projection, popping it lowers the
guard --- the model's \texttt{try/finally} lowers \texttt{\_reprojecting} whether
the nested patch commits or raises.  The outer frame beneath is untouched, so its
delivery set survives and it resumes flushing:

\begin{schema}{AbortReproj}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = setting \land squeue~(\# smode) \neq \langle \rangle \\
  head~(squeue~(\# smode)) \in \ran badK \land sreproj~(\# smode) = on \\
  fields' = ssnap~(\# smode) \\
  smode' = front~smode \land squeue' = front~squeue \\
  \land ssnap' = front~ssnap \land sprops' = front~sprops \\
  \land sreproj' = front~sreproj \\
  guard' = off \land msel' = msel \land dataset' = dataset \\
  \land extern' = extern \land externsel' = externsel \land build' = build
\end{schema}

\begin{schema}{AbortOuter}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = setting \land squeue~(\# smode) \neq \langle \rangle \\
  head~(squeue~(\# smode)) \in \ran badK \land sreproj~(\# smode) = off \\
  fields' = ssnap~(\# smode) \\
  smode' = front~smode \land squeue' = front~squeue \\
  \land ssnap' = front~ssnap \land sprops' = front~sprops \\
  \land sreproj' = front~sreproj \\
  guard' = guard \land msel' = msel \land dataset' = dataset \\
  \land extern' = extern \land externsel' = externsel \land build' = build
\end{schema}

% ============================================================
\section{Delivering Notifications (reentrancy and order)}
\label{sec:deliver}
% ============================================================

A committing frame delivers its props one at a time, in any order.  Delivering a
\texttt{ksel} notification is the model's \texttt{on\_selection\_gesture}: it
folds the element's \emph{committed} selection into the model's full selection:

\begin{schema}{DeliverSel}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = flushing \land ksel \in sprops~(\# smode) \\
  msel' = fields~ksel \\
  sprops' = sprops \oplus \{ \# smode \mapsto (sprops~(\# smode) \setminus \{ ksel \}) \} \\
  smode' = smode \land squeue' = squeue \\
  \land ssnap' = ssnap \land sreproj' = sreproj \\
  fields' = fields \land dataset' = dataset \land extern' = extern \\
  \land externsel' = externsel \land guard' = guard \land build' = build
\end{schema}

Delivering a \texttt{krows} notification runs the model's rows observer.  When
the guard is \emph{up}, the notification is the model's own re-projection write
coming back: the observer returns early and folds nothing --- the self-write
guard:

\begin{schema}{DeliverRowsSkip}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = flushing \land krows \in sprops~(\# smode) \\
  guard = on \\
  sprops' = sprops \oplus \{ \# smode \mapsto (sprops~(\# smode) \setminus \{ krows \}) \} \\
  smode' = smode \land squeue' = squeue \\
  \land ssnap' = ssnap \land sreproj' = sreproj \\
  msel' = msel \land fields' = fields \land dataset' = dataset \\
  \land extern' = extern \land externsel' = externsel \land guard' = guard \\
  \land build' = build
\end{schema}

When the guard is \emph{down}, the notification is an external dataset refresh and
the model runs \texttt{\_absorb\_dataset}: it absorbs the dataset
(\texttt{dataset} becomes the delivered rows value), \emph{folds the element's
committed selection} into its full selection ($msel' = fields~ksel$ --- the
round-4 fix that makes the fold read post-patch state), raises the guard, and
pushes a nested re-projection frame.  That frame writes the filtered subset
(\texttt{b}) into \texttt{krows} and the model's now-current selection
($fields~ksel$) back into \texttt{ksel}.  The nested frame carries its own empty
buffer, and the outer frame's delivery set has already had \texttt{krows}
removed, so the two buffers never share storage:

\begin{schema}{Reproject}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = flushing \land krows \in sprops~(\# smode) \\
  guard = off \land \# smode < maxdepth \\
  dataset' = fields~krows \land msel' = fields~ksel \\
  smode' = smode \cat \langle setting \rangle \\
  squeue' = squeue \cat
    \langle \langle setK~(krows, b), setK~(ksel, fields~ksel) \rangle \rangle \\
  ssnap' = ssnap \cat \langle fields \rangle \\
  sprops' = (sprops \oplus \{ \# smode \mapsto
             (sprops~(\# smode) \setminus \{ krows \}) \}) \cat \langle \emptyset \rangle \\
  sreproj' = sreproj \cat \langle on \rangle \\
  guard' = on \land fields' = fields \\
  \land extern' = extern \land externsel' = externsel \land build' = build
\end{schema}

The same trigger may instead push a re-projection that \emph{aborts} on its
second key --- the model asking ``can the nested patch fail mid-flight?''  Its
rollback restores the fields to the post-outer-commit values, and the outer frame
resumes flushing, so the outer commit is never left half-delivered:

\begin{schema}{ReprojectAbort}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = flushing \land krows \in sprops~(\# smode) \\
  guard = off \land \# smode < maxdepth \\
  dataset' = fields~krows \land msel' = fields~ksel \\
  smode' = smode \cat \langle setting \rangle \\
  squeue' = squeue \cat
    \langle \langle setK~(krows, b), badK~ksel \rangle \rangle \\
  ssnap' = ssnap \cat \langle fields \rangle \\
  sprops' = (sprops \oplus \{ \# smode \mapsto
             (sprops~(\# smode) \setminus \{ krows \}) \}) \cat \langle \emptyset \rangle \\
  sreproj' = sreproj \cat \langle on \rangle \\
  guard' = on \land fields' = fields \\
  \land extern' = extern \land externsel' = externsel \land build' = build
\end{schema}

When a frame has delivered every prop it is popped off every stack sequence.  A
re-projection frame lowers the guard; an outer frame leaves it untouched and,
being the last frame, returns the element to idle:

\begin{schema}{PopReproj}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = flushing \land sprops~(\# smode) = \emptyset \\
  sreproj~(\# smode) = on \\
  smode' = front~smode \land squeue' = front~squeue \\
  \land ssnap' = front~ssnap \land sprops' = front~sprops \\
  \land sreproj' = front~sreproj \\
  guard' = off \land fields' = fields \land msel' = msel \\
  \land dataset' = dataset \land extern' = extern \\
  \land externsel' = externsel \land build' = build
\end{schema}

\begin{schema}{PopOuter}
  \Delta Sys
\where
  \# smode \neq 0 \\
  smode~(\# smode) = flushing \land sprops~(\# smode) = \emptyset \\
  sreproj~(\# smode) = off \\
  smode' = front~smode \land squeue' = front~squeue \\
  \land ssnap' = front~ssnap \land sprops' = front~sprops \\
  \land sreproj' = front~sreproj \\
  guard' = guard \land fields' = fields \land msel' = msel \\
  \land dataset' = dataset \land extern' = extern \\
  \land externsel' = externsel \land build' = build
\end{schema}

Every reachable non-idle state enables at least one operation: a \texttt{setting}
top with a non-empty queue enables \texttt{ApplyStepTop} or an abort; with an
empty queue, a commit; a \texttt{flushing} top with props to deliver enables
\texttt{DeliverSel}, \texttt{DeliverRowsSkip}, or the re-projections; with nothing
left, a pop.  With \texttt{BeginOuter} enabled in every idle state, the correct
design never deadlocks (Section~\ref{sec:verify}).

% ============================================================
\section{The Invariant}
\label{sec:inv}
% ============================================================

Three safety clauses must hold whenever the element is idle ($\# smode = 0$).
They are stated as a predicate over \texttt{Sys}; they are \emph{not} placed in
the \texttt{Sys} schema, because a predicate there would be enforced as a guard on
every successor, silently disabling any operation that would break it and masking
the very defect this model exists to catch.

\paragraph{Invariant AT --- observable atomicity and order-independence.}
When no patch is in progress:
\[
  \# smode = 0 \implies
  (dataset = extern \; \land \; fields~ksel = externsel \; \land \;
   msel = externsel).
\]
The three conjuncts capture the whole contract:

\begin{itemize}
  \item \emph{Dataset (\texttt{dataset = extern}).}  The model's dataset equals
    the dataset the agent last pushed --- the last \emph{external} \texttt{krows}
    write --- not the filtered subset the model's own re-projection wrote back.
    Removing the round-3 guard breaks this: the model folds its own subset in.
  \item \emph{Selection atomicity (\texttt{fields~ksel = externsel}).}  The
    element's committed selection equals the agent's patched selection.  A round-1
    (mutable snapshot) or round-2 (eager notify) defect breaks this --- a
    rolled-back field left ahead, or an un-fired observer left ahead.
  \item \emph{Order-independence (\texttt{msel = externsel}).}  The model's full
    selection equals the agent's patched selection whichever notification the
    commit flushed first.  Because \texttt{sprops} is a set delivered in any
    order, ProB reaches this idle state by every intra-batch order; the clause
    holding across all of them \emph{is} order-independence.  The round-4 defect
    --- re-projecting off the stale full selection when \texttt{rows} flushes
    first --- breaks it on exactly the rows-first order.
\end{itemize}

% ============================================================
\section{Verification}
\label{sec:verify}
% ============================================================

Type-checking is a \texttt{fuzz} pass:
\begin{verbatim}
  fuzz -t docs/patch_atomicity.tex
\end{verbatim}

Invariant AT is checked by asking ProB whether its negation is \emph{reachable};
a goal that is not found means the property holds on every reachable state.  The
operation cap is raised because a single idle state offers many
step-by-step-built outer patches:
\begin{verbatim}
  # Invariant AT (must report: goal NOT found)
  probcli docs/patch_atomicity.tex -model_check -nodead -p MAX_OPERATIONS 500 \
    -goal "size(smode)=0 & (dataset/=extern or fields(ksel)/=externsel
           or msel/=externsel)"
\end{verbatim}

Deadlock-freedom is the state-space search with no goal:
\begin{verbatim}
  # Deadlock-freedom (must report: no deadlock, no error)
  probcli docs/patch_atomicity.tex -model_check -p MAX_OPERATIONS 500
\end{verbatim}

The carriers are concrete free types, so both searches are already exhaustive ---
there is no \texttt{DEFAULT\_SETSIZE} to raise.  Robustness against the bounds is
checked by re-running with \texttt{maxdepth} lowered to \texttt{2} (the correct
design's true maximum depth): the invariant still holds and no deadlock appears,
confirming the depth-three headroom is only there to give the buggy variant room
to recurse.

% ============================================================
\section{Fidelity: reproducing the four defects}
\label{sec:fidelity}
% ============================================================

A model that cannot reproduce the known defects proves nothing.  Each variant is
a single-schema edit; the model checker is re-run, and the named goal must now be
\emph{found} (or, for round~3, a deadlock must appear).  Write $k$ for
$stepKey~(head~(squeue~(\# smode)))$ and $g$ for
$stepVal~(head~(squeue~(\# smode)))$.

\paragraph{Round 2 --- observer notified inside the patch.}
Model eager notification: in \texttt{ApplyStepTop}, instead of adding $k$ to the
frame's \texttt{sprops} buffer, fold it immediately when it is the selection ---
if $k = ksel$ set $msel' = g$, leaving \texttt{sprops} unchanged so nothing is
buffered.  Now a patch that sets \texttt{ksel} then hits a \texttt{badK} folds the
intermediate selection into \texttt{msel}, \texttt{AbortOuter} restores the field
but cannot un-fold the model, and at idle $msel \neq externsel$: the AT goal is
\emph{found}.

\paragraph{Round 1 --- snapshot aliases a mutable model.}
Model the shallow snapshot capturing a shared reference: in \texttt{ApplyStepTop}
mutate the top frame's snapshot alongside the field ---
$ssnap' = ssnap \oplus \{ \# smode \mapsto (ssnap~(\# smode) \oplus \{ k \mapsto g \}) \}$.
Now a patch that sets \texttt{ksel} then hits a \texttt{badK} reaches
\texttt{AbortOuter}, which restores $fields' = ssnap~(\# smode)$ --- but the
snapshot was mutated with the field, so the field is not restored.  At idle
$fields~ksel \neq externsel$: the AT goal is \emph{found} from the opposite side.

\paragraph{Round 3 --- the self-write guard removed.}
Delete \texttt{DeliverRowsSkip} and drop the \texttt{guard = off} conjunct from
\texttt{Reproject} and \texttt{ReprojectAbort}, so every \texttt{krows} delivery
re-absorbs and re-projects.  The nested re-projection's own \texttt{krows} write,
delivered during its commit, is folded straight back in as the dataset ---
$dataset$ becomes the subset \texttt{b} while the agent pushed \texttt{a} --- and
it pushes another re-projection until the depth bound.  Two signals witness it:
\begin{verbatim}
  # the observer folds its own subset in as the dataset
  probcli docs/patch_atomicity.tex -model_check -nodead -p MAX_OPERATIONS 500 \
    -goal "guard=on & dataset/=extern"                    (* found *)
  # the self-recursion, bounded only by the state space
  probcli docs/patch_atomicity.tex -model_check -p MAX_OPERATIONS 500  (* deadlock *)
\end{verbatim}

\paragraph{Round 4 --- the rows-absorb reads the stale full selection.}
Model the pre-fix \texttt{\_absorb\_dataset} that re-projected off the stale full
selection instead of folding the committed one: in \texttt{Reproject} and
\texttt{ReprojectAbort}, drop the $msel' = fields~ksel$ fold (set $msel' = msel$)
and change the nested selection write from $setK~(ksel, fields~ksel)$ to
$setK~(ksel, msel)$ --- the re-projection writes the \emph{stale} model selection
back into the element.  Now a dual \texttt{\{rows, selection\}} patch whose commit
delivers \texttt{rows} first re-projects the stale \texttt{msel} over the
freshly-patched selection, the later \texttt{selection} delivery reads the
clobbered value, and at idle $fields~ksel \neq externsel$ (and $msel \neq
externsel$): the AT goal is \emph{found}.  The selection-first order still
satisfies AT, so the reachability of the violation is precisely the
order-dependence the round-4 fix removed:
\begin{verbatim}
  probcli docs/patch_atomicity.tex -model_check -nodead -p MAX_OPERATIONS 500 \
    -goal "size(smode)=0 & fields(ksel)/=externsel"       (* found *)
\end{verbatim}

\paragraph{Under the correct design none of the four traces exists.}
\texttt{ApplyStepTop} defers every notification into the frame's own buffer and
leaves the snapshot untouched; the aborts restore a value snapshot and fire
nothing; \texttt{DeliverRowsSkip} stops the model re-absorbing its own
re-projection; and \texttt{Reproject} folds the committed selection before writing
it back.  The AT search returns \emph{goal not found}, the round-3 and round-4
goals are unreachable, and the machine is deadlock-free.

The single-patch atomicity partitions remain covered by

\paragraph{The one gap.}  The \texttt{ReprojectAbort} partition --- a nested
re-projection that raises after writing its first key --- is proven safe by the
model (the outer commit finishes delivering, and every AT clause holds at idle)
but has no dedicated test.  In the shipped code a re-projection writes only
validated subset rows and a projected selection, so it does not raise in
practice; the partition guards against a future setter that could.  A regression
test that forces the model's inner \texttt{apply\_patch} to reject its second key
and asserts the outer selection notification still lands would close it.  The
model stands as the regression artefact for the interleaving until then.
