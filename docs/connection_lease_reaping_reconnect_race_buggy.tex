\section{Introduction}
% ============================================================

This is the fidelity control for the register\_client-vs-reap hazard
\texttt{docs/architecture/lease-reap-cascade.md} Section~4 reports, and
for the \texttt{Connect}/\texttt{Renew} mutual-exclusion fix
\texttt{docs/connection\_lease\_reaping.tex} adds to close it. It removes
only the \texttt{$cascadeFor = \emptyset$} guard the fixed spec's
\texttt{Connect} and \texttt{Renew} carry: real
\texttt{register\_client}/\texttt{identify\_client} do not take
\texttt{StoreLock} today, so nothing stops a same-identity reconnect from
landing between \texttt{\_depart\_lapsed}'s registry-and-ownership removal
and its cascade tail, while that tail -- decided against stale
information -- still runs and wipes out the reconnect's just-installed
writer binding. Read the main specification first; this document states
only what differs, in Section~\ref{sec:connect} and
Section~\ref{sec:renew}. The \texttt{TimedReapBegin}/\texttt{TimedReapEnd}
split itself is \emph{not} the bug and is carried over unchanged: it is
the fixed real system's own shape (\texttt{StoreLock} held across the
whole critical section), and this control's only departure from the fixed
spec is that \texttt{Connect}/\texttt{Renew} do not yet respect it.

\label{sec:connect}

\begin{schema}{Connect}

  c? : CONN \\

\where
  registered' = registered \cup \{ c? \} \\
  identity' = identity \oplus \{ c? \mapsto i? \} \\
  transport' = transport \oplus \{ c? \mapsto tup \} \\

\section{Verification: the goal that must flip}
% ============================================================

Against this variant, a live, just-reconnected connection can end up with
no writer bound -- the trace in
\texttt{connection\_lease\_reaping.tex}, Section
``Reconnect-races-reap,'' reaches it in five steps:
\texttt{Connect}(c1, i1); \texttt{LeaseLapse}(c1);
\texttt{TimedReapBegin}(c1); \texttt{Connect}(c1, i1) again -- buggy, no
guard refuses it despite \texttt{cascadeFor = \{c1\}};
\texttt{TimedReapEnd}(c1) -- the stale cascade tail lands after the
reconnect and wipes out the writer it just installed.

\begin{verbatim}
  # must be FOUND against this variant (NOT found against the fixed spec)
  probcli docs/connection_lease_reaping_reconnect_race_buggy.tex \
    -model_check -nodead \
    -goal "#c.(c:CONN & c : registered & hasWriter(c) = fclear)" \
    -p DEFAULT_SETSIZE 3
\end{verbatim}

I2/I3/I5/I6/I7 must stay unaffected -- \texttt{Connect}/\texttt{Renew}
never touch \texttt{registered}, \texttt{owner}, \texttt{hasSubs}, or
\texttt{inboxNonEmpty} any differently from the fixed spec, and this
variant's \texttt{TimedReapBegin}/\texttt{TimedReapEnd} are the fixed
spec's own:

\begin{verbatim}
  # must remain NOT found
  probcli docs/connection_lease_reaping_reconnect_race_buggy.tex \
    -model_check -nodead \
    -goal "#s.(#c.(s:SCENE & c:CONN & owner(s) = conn(c) &
                   not(c : registered)))" \
    -p DEFAULT_SETSIZE 3

  # must remain NOT found
  probcli docs/connection_lease_reaping_reconnect_race_buggy.tex \
    -model_check -nodead \
    -goal "#c.(c:CONN & not(c : registered) & not(c : cascadeFor) &
               (hasSubs(c) = fset or hasWriter(c) = fset or
                inboxNonEmpty(c) = fset))" \
    -p DEFAULT_SETSIZE 3
\end{verbatim}

I1 must stay unaffected -- the chain that establishes I1's positive
outcome does not touch \texttt{Connect}/\texttt{Renew} at all:

\begin{verbatim}
  # must remain FOUND
  probcli docs/connection_lease_reaping_reconnect_race_buggy.tex \
    -model_check -nodead \
    -goal "#c.(c:CONN & c : dom(identity) & not(c : registered) &
               transport(c) = tdown)" \
    -p DEFAULT_SETSIZE 3
\end{verbatim}
